Conditional image loading: CSS display: none isn't enough

This demo uses a CSS display: none with a media query to prevent downloading an image on smaller screens. It does NOT work. It only hides the image after load.

How to test:

  1. Open your browser's Developer Tools and go to the Network tab.
  2. On a desktop viewport (width > 480px for this demo), refresh the page. You will see the image load (placeholder.png).
  3. Resize the window below 480px (or use mobile emulation) and do a hard refresh. The image is still loaded, just hidden.

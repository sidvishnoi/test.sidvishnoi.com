Conditional image loading: Lazy loading + CSS hide

This demo uses loading="lazy" attribute on img, combined with a media query to prevent downloading an image on smaller screens.

How to test:

  1. Open your browser's Developer Tools and go to the Network tab.
  2. On a desktop viewport (width > 480px for this demo), refresh the page. You will see the image load (placeholder.png).
  3. Resize the window below 480px (or use mobile emulation) and do a hard refresh. The image network request is skipped.

This is placeholder to move the image far below the viewport (at least 600vh) to prevent eager loading.

Conditional image loading: Lazy loading + CSS hide with container query

This demo uses the loading="lazy" attribute on an <img>, combined with a container query, to prevent downloading the image when its container is narrow.

How to test

  1. Open your browser's Developer Tools and go to the Network tab.
  2. Refresh the page. The container below starts at 200px wide, so the image (placeholder.png) is not requested.
  3. Make the container wider than 300px, using the slider or by dragging its bottom-right corner. The image is requested and appears.
